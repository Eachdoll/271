## 실행 중 고친 문제와 재개 방식

2. **Node의 로컬 자료 읽기 오류** — K2 r31a의 품질 패키지가 `file:` URL을 Node fetch로 읽어 실패했습니다. 유료 HTTP 오류가 아님을 키 없는 호출로 재현했습니다. `eb41ce4`에서 CLI에 한해 로컬 JSON 읽기를 지원하고, 유료 단계 전에 자료를 미리 읽습니다. 공급자 HTTP 요청은 원래 fetch를 사용합니다.
3. **재개 자료 보존** — 원본 러너가 회의 체크포인트를 JSON에서 빠뜨렸습니다. `eb41ce4`에서 이후 결과에 체크포인트를 포함하도록 보완했습니다. 이번 K2 r31a의 원래 회의 결과는 복구할 수 없어 한 번 더 실행했습니다. 기존 재료와 기존 사용량은 재사용했습니다.
