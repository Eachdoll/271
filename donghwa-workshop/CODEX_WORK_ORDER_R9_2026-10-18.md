## A. "같이 가자" 반복

### 원인 (확인 완료)

r7 규칙으로 새로 만든 줄거리 20편 **전부**와 전문 20편 **전부**에 "같이 가 / 함께 가" 표현이 있다(줄거리 평균 2.5회, 한글 전문 평균 2.0회, 최대 4회). 증류 승인본 161편에는 378회 나온다.

| 원인 | 위치 |
| --- | --- |
| 기본 주인공 유하의 말버릇이 "같이 가자!"이고, 줄거리 프롬프트가 매번 `말버릇 "같이 가자!"`로 넣는다. 사용 횟수 제한이 없어 모델이 여러 비트에 쓴다. | `dist/engine.js` 1077행, `story-quality/src/prompts.ts` `OUTLINE_USER` 첫 줄, `outlinePrompt.ts` 51·62행 |

| 평가·증류 도구도 같은 말버릇을 고정값으로 쓴다. 그래서 증류 예시까지 같은 표현으로 채워졌다. | `story-quality/src/cli/eval.ts` 76행, `distill.ts` 97행, `finetune.ts` 33행 |

### R9-A1 · 말버릇은 책 전체에서 최대 1번 (코드)

1. `OUTLINE_USER`와 앱 일반 줄거리 경로의 등장인물 줄을 `말버릇 "…"(책 전체에서 최대 1번, 꼭 쓰지 않아도 된다. 후렴으로 쓰지 않는다)`로 바꾼다.
2. 전문 단계(패키지 `PROSE_RICH_USER_KO/EN`, 앱 `quality-adapter.js` 전문 규칙, 일반 `pipeline.js` 전문 규칙)에 같은 제한을 넣는다. 영어는 "Use each character's catchphrase at most once in the whole book, or not at all."
3. **최근 책과 돌려 쓰기**: 같은 주인공의 최근 2권 중 한 권이라도 말버릇을 썼다면, 이번 책 프롬프트에서는 말버릇을 빼고 "이번 책에서는 말버릇을 쓰지 않는다"를 넣는다. 최근 책 판정은 기존 금지 목록(`buildBanList`)의 최근 책 창을 재사용한다.
4. **검사**: `plotCheck`와 앱 전문 검사에 "말버릇 2회 이상"을 수정 항목으로 추가한다. 비교는 공백·문장부호를 뺀 핵심 구절로 한다("같이 가자!", "같이 가자", "같이 가!"는 같은 표현).
5. 후렴과 말버릇이 같거나 핵심 구절을 공유하면 수정 항목으로 잡는다.

### R9-A2 · 기본값 정리 (코드·데이터)

1. `refrainTemplates`에서 "○○아, 같이 가자!"를 뺀다.
2. **새로 설치하는 경우에만** 기본 등장인물 말버릇을 서로 다르게 바꾼다. 예: 유하 "내가 먼저 해 볼래!", 초록이 "쿵쿵, 냠냠!", 엄마 "천천히 해도 괜찮아." 이미 저장된 사용자 캐릭터는 바꾸지 않는다.
3. 평가·증류·파인튜닝 도구의 고정 말버릇을 `--catchphrase` 인자(기본 빈 값)로 바꾼다. 기존 결과 파일은 다시 만들지 않는다.
4. 증류 승인본(`approved-books.json`)을 참고 예시로 켤 때, "같이 가" 표현이 2회 이상인 책은 예시 후보에서 뺀다. 원본 파일은 수정하지 않는다.

### R9-A3 · 검증

- 모의 엔진 테스트: 말버릇 3회가 들어간 줄거리·전문은 수정 항목이 생기고, 1회는 통과한다.
- 최근 2권 중 하나가 말버릇을 썼으면 다음 프롬프트에 말버릇 문자열이 없다.
- 기존 사용자 상태(저장된 유하 "같이 가자!")를 불러와도 캐릭터 데이터가 바뀌지 않는다.
- 오프라인 집계: `story-quality/eval/trial-2026-10-17/sonnet55-r7.jsonl`과 `sonnet55-r7-prose-condense.jsonl`에서 새 검사로 걸리는 책 수를 `QA/r9-catchphrase-recheck.json`에 남긴다.

## B. 쉬운 만들기 화면과 프로페셔널 모드

### 현재 상태 (`scripts/ux-census.mjs`로 측정, 1280px)

| 화면 | 보이는 버튼 | 입력 | 선택 | 화면 길이 |
| --- | --- | --- | --- | --- |
| 부모 설정 · 글 엔진·이야기 품질 탭 | 9 | **99** | **64** | **12,266px** |
| 부모 설정 · 그림 World·화풍 탭 | 16 | 10 | 4 | 4,710px |
| 이야기 재료 | 43 | 0 | 0 | 1,696px |
| 만들기 1~4단계 (재료 → 주제·분위기 → 읽기와 형식 → 방식) | 3~13 | 0~3 | 1~6 | 약 1,300px |
| 작업 창 · 줄거리 카드 | **108** | 21 | 0 | |
| 작업 창 · 쪽 나누기 | **162** | 75 | 25 | |
| 이야기 다듬기 (편집) | 35 | 4 | 0 | 2,285px |

지금 한 권을 만들려면 만들기 4단계 → 작업 창 3단계(줄거리 카드·전문·쪽 나누기) → 이야기 다듬기 → 확정, 사실상 8단계를 거친다. 줄거리 카드에는 비트마다 감정 칩 10~11개와 장소 칩이 펼쳐져 있다. 쪽 나누기에는 쪽마다 카메라 거리·시점·위치 버튼 10여 개가 있다.

### 목표 흐름 (기본 모드)

```
① 주제 넣기 → ② 재료 고르기 → ③ 생성 (글 엔진 · 그림 엔진) → ④ 쪽마다 검수 → ⑤ 동화책 만들기
```

화면 위에 다섯 단계 표시줄 하나만 둔다. 작업 창(팝업)을 쓰지 않고 한 페이지에서 단계가 넘어간다.

#### ① 주제 넣기

- 큰 입력칸 하나와 주제 예시 칩 6개, "아이디어 뽑기" 버튼.
- 책 형식은 한 줄 요약으로만 보인다. 예: "한글 K1 · 영어 E0 · 12쪽 · 한글판·영어판 두 권 [바꾸기]". [바꾸기]를 누르면 작은 패널에서 읽기 수준, 언어, 쪽 수만 고른다. 나머지 형식(인쇄 배열 등)은 프로페셔널 모드와 부모 설정 기본값을 따른다.
- 교훈·마무리 방식·분위기는 기본 모드에서 숨기고 부모 설정 기본값을 쓴다.

#### ② 재료 고르기

- 주인공은 미리 선택되어 있다. 친구(최대 2명)와 장소 카드를 고른다.
- 주제에서 추천한 장소·친구에 "추천" 표시를 하고 미리 선택해 둔다.
- "부족한 재료 자동 추가"는 기본 켬, 체크 하나로만 보인다.
- 캐릭터 시트 생성, 옷장, 사진으로 만들기 같은 재료 관리 기능은 이 단계에 두지 않는다. "이야기 재료" 메뉴와 프로페셔널 모드에 그대로 둔다.

#### ③ 생성

- **글 엔진** 선택 하나, **그림 엔진** 선택 하나. 각각 이름과 예상 비용 한 줄을 보인다. 키가 없는 엔진은 "키 입력" 버튼으로 부모 설정의 해당 칸으로 바로 이동한다.
- 큰 버튼 하나: **이야기 만들기**. 내부적으로는 기존 FULL AUTO 경로(줄거리 → 전문 → 쪽 나누기 → 그림)를 그대로 쓴다. 진행 표시는 "줄거리 · 글 · 쪽 나누기 · 그림 n/12" 한 줄과 진행 막대만 둔다.
- 증류 예시 사용은 버튼 하나로 둔다: "승인 예시 함께 쓰기 [켜기/끄기]". 기본 끔이고, 설명은 물음표 툴팁 한 줄이다.
- 엔진 단계별 선택(줄거리·전문·심사 모델 따로), 패턴, 세계 카드, 계절·시간, 품질 옵션은 기본 모드에서 숨기고 기본값을 쓴다.

#### ④ 쪽마다 검수

- 한 화면에 한 쪽씩 보인다: 그림, 한글 글, 영어 글. 좌우 화살표와 "n / 12" 표시가 있다.
- 쪽마다 버튼은 네 개만 둔다: **글 고치기**(제자리 편집), **글 다시 만들기**, **그림 다시 만들기**, **좋아요**(검수 완료 표시).
- 글을 고치거나 다시 만들면 "이 쪽 그림도 다시 만들까요? (약 $n)" 확인을 띄운다. 자동으로 다시 결제하지 않는다.
- 읽기 검사 결과는 쪽 아래 한 줄 배지로만 보인다(예: "읽기 쉬움 ✓", "문장이 길어요 2곳"). 배지를 누르면 상세 위반 목록이 열린다.
- 위쪽에 "이야기 전체 다시 만들기" 버튼 하나를 둔다. 누르면 비용 확인 후 ③으로 돌아간다.
- 카메라 거리·시점·위치, 쪽 합치기·나누기, 비트별 감정·장소 칩, 장면 브리프, 일관성 검사 상세는 프로페셔널 모드에만 둔다.

#### ⑤ 동화책 만들기

- 표지 미리보기, 제목 후보 3개 중 고르기, "인쇄 미리보기", **책장에 저장** 버튼.
- 저장 뒤에는 책 상세 화면으로 간다. "다음 편 만들기" 버튼은 ①로 돌아가되 같은 재료를 미리 고른다.

### R9-B1 · 모드 전환 (코드)

1. 설정에 `uiMode: "simple" | "pro"`를 추가한다. 기본값은 `"simple"`이다. 기존 사용자도 처음 열 때 기본 모드로 시작하고, 부모 설정 맨 위와 만들기 화면 오른쪽 위에 "프로페셔널 모드" 전환 스위치를 둔다.
2. 프로페셔널 모드는 **지금 화면 그대로**다. 기능을 지우지 않는다. 기본 모드는 같은 상태와 파이프라인 위에 얹는 별도 화면이다.
3. 아이 모드와는 별개다. 아이 모드 규칙은 바꾸지 않는다.
4. 진행 중 초안이 있으면 두 모드 어디서든 이어서 연다. 기본 모드에서 열 때는 단계를 이렇게 대응한다: 줄거리·전문·쪽 나누기 진행 중 → ③(진행 표시), 편집 단계 → ④, 확정 대기 → ⑤.

### R9-B2 · 기본 모드 만들기 화면 (코드)

1. 위의 다섯 단계를 새 화면(예: `dist/simple-create.js`)으로 만든다. 상태 저장, 비용 계산, 키 확인, FULL AUTO 실행·재개·중지, 쪽 단위 재생성은 기존 함수를 그대로 호출한다. 파이프라인 로직을 복제하지 않는다.
2. FULL AUTO의 "닫아도 중지 아님", 완료한 유료 단계 재결제 방지, 고정 설정 스냅샷 규칙을 그대로 따른다.
3. 각 단계 화면에서 **보이는 버튼은 12개 이하**로 한다. ②의 재료 카드와 ④의 쪽 이동 화살표는 세지 않는다.

### R9-B3 · 기본 모드 부모 설정 (코드)

기본 모드의 부모 설정은 한 화면, 네 묶음만 보인다.

| 묶음 | 내용 |
| --- | --- |
| 우리 아이 | 아이 이름, 기본 읽기 수준(한글·영어), 책 형식 기본값 |
| 엔진과 키 | 글 엔진 하나, 그림 엔진 하나, 각 키 입력·삭제 |
| 잠금 | 부모 PIN 바꾸기 |
| 보관 | 다른 기기로 옮기기, 백업, 가져오기 |

그 밖의 항목(단계별 모델, 이야기 품질, 패턴 편집, 금지 예시, 코치, 세계·계절, World 배리에이션, 캐릭터 시트, 화풍 프리셋, 엔진 비교, 화풍 작업실, 추가 금칙어 등)은 프로페셔널 모드에만 보인다. 값은 그대로 유지되고 기본 모드 생성에도 적용된다.

### R9-B4 · 버튼으로 남길 기능 (코드)

자주 쓰는 동작은 기본 모드에서 버튼 하나로 노출한다. 세부 옵션은 프로페셔널 모드에 남긴다.

| 기능 | 기본 모드 위치 | 동작 |
| --- | --- | --- |
| 쪽 글 다시 만들기 | ④ 쪽마다 | 해당 쪽만 재생성, 비용 확인 |
| 쪽 그림 다시 만들기 | ④ 쪽마다 | 해당 쪽만 재생성, 비용 확인 |
| 이야기 전체 다시 만들기 | ④ 위쪽 | 비용 확인 후 ③으로 |
| 승인 예시 함께 쓰기(증류) | ③ | 켜기/끄기 버튼 |
| 다음 편 만들기 | 책 상세 | 같은 재료로 ① |
| 복사본으로 고치기 | 책 상세 | 기존 기능 연결 |

### R9-B5 · 검증

- `scripts/ux-census.mjs`를 기본 모드 흐름에도 돌려, 단계별 보이는 버튼 수를 `QA/r9-ux-census.json`에 남긴다. 위 표의 프로페셔널 모드 수치는 그대로여야 한다(기능을 지우지 않았다는 확인).
- PC 1280px·모바일 390px에서 기본 모드로 데모 엔진 한 권 만들기를 끝까지 진행한다: ①→⑤, 저장, 재접속, 읽기. 페이지 오류·유료 요청·가로 넘침이 없어야 한다.
- 기본 모드에서 시작한 초안을 프로페셔널 모드에서 열고, 그 반대도 확인한다.
- 모드 전환이 저장된 설정·초안·책을 바꾸지 않는지 확인한다.
