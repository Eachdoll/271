# 1쪽을 먼저 그려 무대 참고로 쓰기 — 실측 (2026-11-12)

부모님 요청: "1쪽 그림 먼저 만들어서 무대 참고로 써봐"

## 한 일

R63 코드로 '빵 냄새는 등 뒤에서'의 1·3·15쪽 그림을 실제로 만들었습니다.

- 그림 요청은 앱의 함수 그대로 만들었습니다: `createCharacterSheetRequest`, `sceneGenerationRequest`, `generateImage`.
- 엔진: OpenAI `gpt-image-2`, 화질 medium, 1536×1024.
- 키는 실행 프로세스 환경에만 두었습니다. 출력에서 키 모양 문자열을 검사했고, 0건이었습니다.
- 순서:
  1. 유하 캐릭터 시트 1장 — 이 실험용 시드에는 확정 시트가 없어서 새로 만들었습니다.
  2. 1쪽: 마을 입구, 거꾸로 선 화살표 표지판, 길 오른쪽 끝의 빵집.
  3. 3쪽과 15쪽: 앱이 1쪽 그림을 `CANONICAL first scene at SAME place, page 1` 참고로 자동으로 붙였습니다(R63의 무대 키). 15쪽에는 3쪽도 `Recent scene from the SAME camera`로 붙었습니다.
- 그림 읽기 값(mustSee, 무대 지도, 표지판 생김새, 새 아이 생김새)은 R63 지시가 요구하는 형태로 손으로 채웠습니다. 유료 글 호출은 없었습니다.
- 그림 4장은 스크래치에만 두고 커밋하지 않았습니다(`r64/out/*.png`). 요청 전문은 이 폴더의 `*-request.txt`에 있습니다.
- 요금: 공급자 응답에 청구 금액이 없어 기록되지 않았습니다(4장, medium).
- 걸린 시간: 장당 25~41초.

## 결과 (눈으로 확인)

| 항목 | 1쪽 | 3쪽 | 15쪽 |
|---|---|---|---|
| 화살표 표지판 | 철 받침대에 매단 나무판, 빨간 아래 화살표, 왼쪽 참나무 | 같음 | 같음 |
| 길·돌담 | 왼쪽에서 오른쪽으로 난 흙길, 돌담 | 같음 | 같음 |
| 빵집 | 오른쪽 끝, 초록·크림 줄무늬 차양 | 같은 빵집, 더 작고 멀리 ("점점 작아졌어요") | 같은 빵집 |
| 인물 | 유하(시트와 같음) | 유하가 다시 표지판 밑, 놀란 얼굴 | 새 아이(빨간 모자·멜빵바지·노란 가방, 유하와 확실히 다름), 유하는 빵집을 등지고 아이를 마주 보며 한 발 듦 |

부모님이 짚은 "화살표가 계속 바뀜", "새 친구라는데 유하", "그림 연결성"은 이 세 쪽에서 해결된 모습입니다.

## 아직 확인하지 않은 것

- 뒷걸음 자세 쪽(7·9쪽)
- 빵집 안 장면
- 펼침 책
- 실제 유료 글 호출이 만든 그림 읽기 값으로 그린 경우

실제 책 한 권 전체로 확인하려면, 부모님 승인 뒤 같은 방식으로 그리면 됩니다.

```bash
DRY=1 node QA/r64-stage/tools/stage-run.mjs <out>   # 요청만, 네트워크 0

```

키는 실행 환경 변수로만 넘깁니다.
