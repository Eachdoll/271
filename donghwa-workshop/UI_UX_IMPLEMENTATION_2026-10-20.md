## 스위치가 뜻하는 범위

- **증류 추가 예시**: 기존 `useDistilledExamples` 설정입니다. 켜면 승인 예시 범위를 늘리며, 꺼도 기존 정책에 따라 기본 9점 이상 예시는 유지합니다. 별도의 증류 작업이나 유료 생성은 시작하지 않습니다.
- **회의 후 부모 확인**: 기존 `councilReview` 설정입니다. 켜면 이야기 안 선택에서 기다리고, 끄면 봇 추천으로 자동 진행합니다. 회의 생성 자체를 생략하는 스위치가 아닙니다.
- 생성 중인 이야기는 시작할 때 고정한 값을 표시합니다. 이후 부모 기본값을 바꾸어도 그 이야기의 값은 달라지지 않습니다.

요금은 공급자 실제 청구액이 아닌 앱의 추정입니다. 이미 저장된 사용량과 앞으로 할 작업의 예상액을 따로 계산하며, 모르는 모델 단가는 ‘요금 정보 없음’ 또는 ‘일부 미확인’으로 표시합니다. 자동 수정·그림 비용은 별도입니다. 생성 엔진·단계별 모델·재시도·가격 계산 정책은 바꾸지 않았습니다.
