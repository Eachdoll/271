## 1. 무엇이 바뀌었나 (새 초안에만, `input.craftPolicy`)

| 평가에서 나온 문제 | 규칙 |
| --- | --- |
| 2쪽에서 소리의 정체(이름표 고리)를 말해 버림 | 줄거리·본문·쪽 나누기에 '수수께끼 보호': 답과 원인은 전환 비트부터. 그 전에는 단서와 틀린 짐작만 |
| 소리 이야기에 소리말이 없음('가는 소리') | 소리는 의성어로 쓰기('딸랑!'). K1·K2 한글 책은 소리말 후렴(의성어 한 줄, 비트 3곳) 필수. 누락은 참고 항목(멈추지 않음) |
| 문장이 길고 설명조 | K1·K2는 한 문장에 한 동작. 이유·방법은 따로 짧은 문장이나 그림에 |
| 토토가 끄덕이기만 함 | 조연이 틀린 짐작이나 엉뚱한 시도를 한 번은 하도록 |
| 달 언덕 여섯 쪽이 같은 구도 | 같은 장소 세 쪽째부터 그림 요청에 '카메라 변화'(거리·방향·부분을 바꾸기) |
| 글의 핵심 소품(고리)이 그림에 안 보임 | 쪽 나누기가 글에 나온 소품을 장면 설명에 적고, 그림 요청이 '핵심 소품 크게'를 덧붙임. 장면 설명에 빠지면 검사 카드에 참고 표시 |
| 아침 정원에 초승달 | 낮 시간대 그림 요청에 '달·별 없음'(글이 달을 말하면 글대로) |
| 승인 예시가 수준과 무관 | 승인 예시 사용 시 같은 한글 수준 예시가 10편 이상이면 그 수준만 |

편집자 통독도 '수수께끼'와 '소리말' 항목을 봅니다. 기존 초안·작업·책은 바이트 단위로 같습니다.
