# Claude Code 개발 안내

이 프로젝트는 동화공방의 실제 소스입니다. 먼저 `CLAUDE_CODE_START_HERE.md`, `README.md`, `STORY_QUALITY_INTEGRATION.md`를 읽으세요.

## 편집 위치

- **루트 `dist/`는 편집하는 프런트엔드 소스입니다.** 일반적인 빌드 산출물로 취급해 삭제하거나 덮어쓰지 마세요. 빌드 도구 없이 ESM JavaScript로 실행합니다.
- `story-quality/src/`는 TypeScript 원본입니다. 수정 후 빌드하여 `story-quality/dist/`와 프런트엔드의 `dist/story-quality/` 사본을 동기화합니다. 루트 `npm run build`가 이 작업을 합니다.
- `server/cloud-api.js`는 계정별 D1/R2 보관 API입니다. `cloud-runtime/`는 Vinext/Cloudflare Worker 런타임이며 `db/schema.ts`와 `drizzle/`에 스키마·마이그레이션이 있습니다.
- `cloud-runtime/public/`, `cloud-runtime/dist/`, `.wrangler/`, `node_modules/`는 생성물이므로 직접 수정하지 않습니다.

## 검증

Node.js 22.13 이상을 사용하세요. 컴파일된 패키지가 포함되어 있어 아래 테스트는 의존성 설치 없이 실행할 수 있습니다.

```bash
npm test
npm run test:quality
```

전체 빌드에는 `npm --prefix cloud-runtime ci`가 먼저 필요합니다. 이후 루트에서 `npm run build`를 실행합니다. 상세한 로컬 실행·DB 준비 명령은 시작 문서에 있습니다.

## 유지할 동작

- 이미지 엔진 World와 이야기 세계 카드 100종은 별개입니다. 계절·시간 분위기를 적용하면서 승인 배경의 구조, 캐릭터 시트, 화풍 참조, 시드와 책별 설정 스냅샷을 보존합니다.
- 새 줄거리의 `plotContract`에는 원인·시도·결과·다음 결정과 인물/소품 상태가 연결됩니다. 최종 쪽의 일관성 검사 결과는 검수한 내용 지문에 묶여야 합니다. 오래된 통과 결과로 그림을 생성하면 안 됩니다.
- FULL AUTO 상세 창을 닫는 것은 중지가 아닙니다. 명시적 중지·부모 잠금·브라우저 종료에서만 실행을 중단하며 유료 응답과 진행 상태를 보관합니다. 재개 시 완료 호출을 다시 결제하지 않게 하세요.
- r7 새 규격은 K1 쪽당 2~3문장·시도 최대 2번, E0 쪽당 1~2문장·어휘 경고입니다. 기존 `readingLevelSnapshot`과 고정 비트 수를 최신 기본값으로 덮어쓰지 않습니다. E1의 1문장·10% 차단은 유지합니다.
- r8 새 K1/E0 초안의 `input.prosePolicy`는 언어별 압축 여부를 고정합니다. 기록이 없는 기존 초안은 OFF이며 설정 변경·재접속 때 소급 활성화하지 않습니다. 문장 분리는 앱/패키지 공유 함수로 유지하고, 원본 유료 결과는 별도 QA로만 재검사합니다.
- r9 말버릇 규칙: 새 초안의 `input.catchphrasePolicy`(`limit` 1, 최근 승인 2권에서 쓴 주인공은 `omit`)를 `inputFromWizard`에서 고정합니다. 기록이 없는 기존 초안은 R9 이전 프롬프트와 바이트 단위로 같아야 합니다. 비교는 `story-quality/src/catchphrase.ts` 공유 함수로 합니다. 앱 줄거리의 말버릇 항목은 권고이며 말버릇만 걸렸을 때 유료 수정 호출을 하지 않습니다. 저장된 사용자 캐릭터의 말버릇은 바꾸지 않습니다.
- 화면 모드는 기기별 `localStorage` `donghwa-ui-mode`(`simple` 기본 | `pro`)입니다. 프로페셔널 모드는 기존 화면 그대로 두고, 쉬운 만들기(`dist/simple-create.js`)는 파이프라인을 복제하지 않고 FULL AUTO(`stopBefore: "text"`)와 `page-tools.js`를 호출합니다. 단계마다 보이는 버튼은 12개 이하로 유지합니다.
- R11 쉬운 만들기 단계 이동: 단계 표시의 버튼은 `data-simple-nav`를 달고 12개 버튼 수에서 빠집니다. 작업(FULL AUTO job)이 생긴 뒤 ①/②는 그 작업의 고정된 사본만 보여 주고, 바꾸려면 '이 주제로 새로 만들기'로 새 이야기를 시작하며 이전 작업은 손대지 않고 남깁니다. 단계 이동(단계 표시·이전/다음·검수로 가기·브라우저 뒤로/앞으로)은 화면만 바꾸며 무엇도 시작·재개·결제하지 않습니다.
- 산 그림은 다시 사지 않습니다. 글을 고친 쪽의 그림은 부모가 고르기 전에는 다시 그리지 않고(`simpleTextEditedAssetId`), 확정은 이미 있는 최종 그림을 유지하며, FULL AUTO 작업이 가진 초안은 이야기에서 다시 엮지 않습니다.
- 그림 금칙어는 모든 그림 요청이 `imageWordCheck({strict, lenient, names})`로 검사할 부분을 선언하고 `checkForbiddenWords` 하나로 검사합니다. 부모가 적은 글은 엄격, 모델이 쓴 글(쪽 본문·장면·브리프·앞쪽 글, 부모가 고치지 않은 FULL AUTO 재료)은 관대, 앱 고정 지시문·플롯 장부는 검사하지 않습니다. 고정 지시문에 금칙어(예: "FROZEN")를 넣지 마세요.
- `storyDate`와 세계/계절/시간 설정은 제작 시점에 고정합니다. 재접속 날짜로 계절을 다시 계산하지 않습니다.
- 키는 브라우저 PIN 기반 AES-GCM 보관함 또는 별도 프록시 환경변수에서만 읽습니다. 라이브러리·프롬프트·로그·백업·소스에 키를 넣지 않습니다. 추적 ID `key_...`는 OpenAI API 비밀 키가 아닙니다.
- 서버는 Sites가 검증해 전달한 인증 헤더를 신뢰합니다. 다른 호스팅에 옮길 때 클라이언트가 보낸 같은 이름의 헤더를 인증으로 쓰지 마세요. 출처·계정 일치·CAS 버전 검사는 유지하세요.
- 새 DB 변경은 Drizzle 마이그레이션으로 추가합니다. 이미 적용한 SQL을 덮어쓰거나 요청 처리 중 DDL을 실행하지 않습니다.
- API 오류 때 샘플 그림·고정 이야기로 자동 대체하지 않습니다. 모의 테스트 통과와 실제 유료 모델의 글/그림 품질 평가는 구분합니다.
- 유료 `distill`, `eval`, 코치, 파인튜닝 실행은 사용자가 요청한 범위에서만 합니다. `topics:gen`과 `distill:estimate`는 모델 호출 없이 실행됩니다. 2026-10-17 증류 200편을 실행했고 승인본은 161편입니다. 원본·승인본·요약은 `story-quality/distill/runs/2026-10-17/`에 보존합니다. 앱에서의 증류 예시 사용은 R6-4의 명시적 옵션이며 기본 OFF입니다.

## 변경 전달

이 압축본은 Git 자격 증명·사용자 DB·실제 API 키를 포함하지 않습니다. 압축을 푼 뒤 자체 Git 저장소를 시작하고 기능별로 커밋하면 후속 통합이 쉽습니다. 기존 `.openai/hosting.json`의 프로젝트 ID는 현재 사이트의 식별자입니다. 소스 수정만으로 운영 사이트에 자동 배포되지 않으며 배포 권한과 호스팅 연결은 별도입니다.
