## 포함 기능

- **쉬운 만들기(기본)와 프로페셔널 모드**: 기기마다 `localStorage` `donghwa-ui-mode`(`simple` 기본 | `pro`)로 고르며 부모 설정 맨 위와 만들기 화면에서 바꿉니다. 쉬운 만들기는 ① 주제 넣기 → ② 재료 고르기 → ③ 글 만들기(글·그림 엔진 각각 선택, 그림은 아직 만들지 않음) → ④ 쪽마다 검수(글 고치기·글 다시 만들기·그림 만들기·좋아요, 모든 쪽 그림 만들기) → ⑤ 동화책 만들기 다섯 단계이고, 단계마다 보이는 버튼은 12개 이하입니다(단계 표시 버튼은 `data-simple-nav`로 따로 셉니다). 갈 수 있는 단계는 단계 표시를 눌러, 또는 이전/다음·검수로 가기·브라우저 뒤로/앞으로 오가며, 이동은 화면만 바꿀 뿐 아무것도 시작·재개·결제하지 않습니다. 글을 만들기 시작한 이야기의 ①/②는 그 이야기의 주제·형식·재료를 보여 주기만 하고, 바꾸려면 ‘이 주제로 새로 만들기’로 새 이야기를 시작합니다(지금 이야기는 그대로 남고, 새 이야기는 ③ 글 만들기에서만 비용이 듭니다). 브라우저 뒤로 가기는 고치던 글이 있으면 막히되 앱을 떠나지 않고, 첫 단계 앞에서는 ‘책장으로’와 같은 확인을 거쳐 앱 안의 책장으로 가므로 진행 중인 글·그림 만들기가 끊기지 않습니다. 단계를 옮기면 키보드 초점이 새 단계로 갑니다. 아래 버튼 줄은 화면 아래에 고정되고, ④는 마지막으로 본 쪽에서 다시 열리며, 쉬운 모드 책장은 ‘제작 중인 이야기’를 맨 위에 쉬운 말로 보여 줍니다(쉬운 단계로 열 수 있는 쉬운 작업과 책이 있는 작업만, 책이 없는 프로 FULL AUTO 작업은 책 아래 프로 목록에 남고, ③은 어떤 작업이든 글까지만 만듭니다). 부모 설정은 우리 아이·엔진과 키·잠금·보관 네 묶음만 보입니다. 프로페셔널 모드는 기존 화면 그대로이며, 두 모드는 같은 상태·FULL AUTO·쪽 단위 도구(`story-generation/page-tools.js`)를 씁니다.
- **펼침 구성 그림책(R12)**: 새 K2~K4 책 중 한글이 있는 책(한글만·한영·두 언어)은 종이 그림책처럼 펼침(마주 보는 두 쪽) 단위로 만듭니다. 12쪽은 펼침 6개, 16쪽(기본)은 펼침 8개이고 비트 하나가 펼침 하나입니다. AI가 펼침마다 두 쪽을 잇는 큰 그림 한 장(펼침면, 21:9)과 왼쪽·오른쪽 낱쪽 그림 두 장(낱쪽) 중 하나를 고르고, 화면은 그 이유(예: ‘펼침면 · 새 장소에 도착’)를 보여 줍니다. 그래서 그림 수는 책마다 다릅니다(16쪽이면 보통 8~15장 + 표지, ③에 범위를 미리 표시). 한글 분량은 펼침 하나에 K2·K3 10~15문장, K4 10~16문장이고 영어는 지금과 같은 인쇄 쪽당 분량입니다. 쉬운 만들기 ④·프로 쪽 나누기·편집기·읽기 화면·책장은 ‘펼침 2 · 3쪽(왼쪽)’, ‘펼침 1 · 1–2쪽 펼침면’처럼 표시하고, 그림이 생긴 뒤에는 펼침면/낱쪽 구성을 바꾸지 않습니다. 인쇄는 ‘한 장에 펼침 하나’(A4 가로, 펼침면은 두 쪽에 이어 인쇄)와 ‘크게 읽기’(A4 세로 한 장에 한 쪽)이며 소책자는 아직 지원하지 않습니다(고르면 한 장에 펼침 하나로 인쇄하고 안내합니다). K1, 영어만인 책, 이미 있는 초안·작업·책은 지금과 똑같은 쪽 책입니다.
- **가족 아이디 계정(R11)**: ChatGPT 계정 없이 아이디·비밀번호로 PC·휴대폰·태블릿이 같은 책장을 씁니다. 계정 만들기에는 사이트 관리자가 따로 전한 가족 초대 코드가 필요하고, 가입 때 한 번만 보여 주는 복구 코드, 비밀번호 변경(다른 기기 로그아웃 선택), 계정 삭제(이 기기의 책은 남음), 잠긴 기기의 ‘이 기기 자료로 계속 쓰기’를 제공합니다. ChatGPT 로그인도 그대로 쓸 수 있으며 규칙은 아래 ‘계정별 클라우드 동기화’에 있습니다.
- **엔진 세부 선택(R13)**: 글과 그림 모두 공급자(GPT·Claude·Gemini·로컬 / OpenAI·Google·BFL·fal·ComfyUI·무료 샘플)를 고른 뒤 모델을 고릅니다. 모델은 요금 확인한 추천 목록(예: ‘GPT-6.1 Sol · 고급 · 입력 $2 / 출력 $10 per 1M’), 무료 ‘모델 목록 불러오기’(OpenAI·Anthropic·Google·로컬의 목록 API, 프록시를 쓰면 프록시의 키로)로 받은 목록, 직접 입력한 모델 ID에서 고르며, 목록에 없는 모델은 온도·추론 설정 없이 단계 출력 한도만 보내고 요금은 ‘요금 정보 없음’으로 표시합니다. 쉬운 만들기 ③에서 고른 글 모델은 줄거리·글·쪽 나누기·검사에 쓰고 보조 호출은 기본 경제형 모델 그대로이며, 작업과 책은 만들 때의 글·그림 모델을 고정합니다.
- 말버릇은 책 전체에서 최대 1번입니다. 같은 주인공의 최근 승인 2권 중 한 권이라도 말버릇을 썼으면 이번 책에서는 빼며, 새 초안의 `input.catchphrasePolicy`에 고정합니다. 기록이 없는 기존 초안은 r9 이전 요청 그대로입니다.
- 부모 PIN, 읽기 전용 아이 모드, 책장·즐겨찾기·시리즈·인쇄·음성 합성
- 등장인물·배경 설정 수정, 삭제와 복원, 이전 책의 외모·장소 스냅샷 보존
- 이야기 주제별 조연 설정 추천 → 선택한 World 엔진으로 시트 생성 → 부모 확인 → 재료 서랍·작성 중 이야기 추가
- 사진 1~3장으로 캐릭터 시트·World별 배경 시트 생성(사진의 구조·창·문·가구·소품과 고정 배치 보존), 완성 그림 무료 가져오기. 원본 사진은 메모리에만 보관하고 정리하며, 생성 결과만 IndexedDB에 저장
- Google·OpenAI·BFL·fal·ComfyUI 이미지 플러그인, 기기 내 무료 그림 템플릿, AES-GCM API 키 보관, 같은 프롬프트 3개 엔진 비교

- 캐릭터 옷장 정면·전신 2장 승인, 책별·쪽 범위별 모습 선택, 추천 사전·부모 요청 Google API로 한글 설명을 영어로 번역

## 생성과 검사 범위

이야기는 별도 글 엔진으로 줄거리 비트 → 한글·영어 전문 → 쪽 나누기의 세 단계 LLM 호출을 사용합니다. 부모가 단계별 승인·수정·부분 재생성을 하며 단계 결과는 초안에 저장합니다. 로컬 모델과 API 최종 전문을 합친 하이브리드도 지원합니다. 부모 설정에서 GPT-6.1 Sol·GPT-6 Astra, Gemini 4 Argon, Claude Sonnet 5.5·Opus 5.5·Fable 5.1 등 상위 글 모델을 선택하고 모델별 요금으로 추정합니다. 이전 초안의 모델은 명시적으로 설정을 적용할 때만 바뀝니다. 7비트와 12쪽을 구분하고 쪽 수가 맞지 않는 저장 초안은 기존 글을 보존해 복구할 수 있습니다. API 실패를 템플릿으로 대체하지 않으며 고정 데모는 명시적 버튼과 라벨로 구분합니다. 조연 설정 추천은 기기 내 주제별 후보입니다. 자세한 규칙은 [글 생성 문서](TEXT_GENERATION.md)를 참고하세요.

다음 편은 이전 책의 원문·최종 장면·인물 관계·장소·결말을 읽고 새 사건을 만듭니다. 그림은 이전 편의 확정 캐릭터·스타일·집/방/장소 참조를 유지하며 해당 쪽의 장소만 참조합니다. 이전 책과 재료는 보존합니다.

그림은 부모가 생성 버튼을 누를 때 선택한 공급자 API 또는 ComfyUI로 생성합니다. 무료 샘플 엔진은 고정 SVG/Canvas 템플릿이며 사진 변환, 커버의 정교한 수채화, 이미지 레퍼런스 해석을 수행하지 않습니다. Google Gemini 웹 앱의 무료 한도는 이 앱의 API 호출에 사용할 수 없습니다. 웹 앱에서 직접 만든 그림을 내려받아 무료로 가져올 수 있습니다. [공식 Google API 요금표](https://ai.google.dev/gemini-api/docs/pricing)와 [이미지 플러그인 문서](IMAGE_GENERATION.md)를 참고하세요.

읽기 검사는 Python 없이 브라우저에서 FK, Revised Spache와 Dale–Chall 공식을 직접 계산합니다. 음절 수와 한글 연결어미는 휴리스틱이며 공식 AR·Lexile·KReaD 점수가 아닙니다. 공개 Dolch·Fry 및 각 지수의 독립 친숙 어휘 데이터를 포함합니다. 한글 등급 자료가 없으면 어휘 검사만 생략하며 부모가 CSV를 넣을 수 있습니다. 기본값은 K1/E0, SR과 난이도 피드백은 추천 후 부모 확인 방식입니다.

캐릭터·옷장·사진 후보는 draft로 먼저 확인하고, 최종 생성 버튼에서 final 품질로 다시 만들고 승인합니다. 스타일 시험과 엔진 2~3개 비교는 draft입니다. 책 확정에서 최종 본문과 표지를 만들기 전 예상 비용을 확인합니다. 실제 API가 금액을 반환한 경우에만 실제 비용을 기록하며 나머지는 추정입니다. 모델과 참고 단가는 `image-generation/models.js`에 모았습니다.

[로컬 Node 이미지 프록시](image-proxy/README.md)를 선택적으로 연결할 수 있습니다. 프록시에서는 환경변수 키만 사용하고 브라우저의 저장된 키를 보내지 않습니다. 정적 Site 자체는 Node 프록시를 실행하지 않습니다.

부모 녹음은 언어별로 TTS보다 먼저 재생합니다. OpenAI 키가 있으면 승인 후 쪽별 음원과 타임스탬프를 저장할 수 있으며, 키가 없을 때의 기기 음성은 사전 저장할 수 없습니다. 녹음·정렬 실패의 하이라이트는 근사 위치로 표시합니다. 음원도 백업/복원에 포함합니다. 이어 듣기 기본 OFF, 손 넘김과 스와이프는 재생을 시작하지 않습니다.

## 저장과 실행

로그인한 계정의 책·재료·World는 D1의 버전 정보와 R2의 스냅샷·미디어로 보관합니다. 브라우저에는 작업 중 보관본과 큰 그림·음원을 localStorage·IndexedDB에 캐시합니다. API 키 평문과 원본 사진은 라이브러리 백업에 포함되지 않습니다. PIN 화면 잠금 해시와 별도로 API 키는 PIN에서 PBKDF2로 파생한 AES-GCM 키로 암호화합니다. 파생 암호화 키는 메모리에만 두고 PIN 변경 때 저장된 API 키를 다시 암호화합니다. 기기 내 PIN은 서버 인증을 대신하지 않습니다. 새로고침하면 부모 잠금이 다시 걸립니다. 로그인은 가족 아이디와 ChatGPT 계정 두 가지이며(아래 ‘계정별 클라우드 동기화’), 같은 계정으로 연결한 기기는 클라우드 자료를 자동으로 불러오고 부모 모드의 변경을 자동 저장합니다. 아이가 책을 읽기만 한 저장은 변경으로 세지 않습니다.

기본 인쇄는 A4 가로 한 면 한 쪽, 빈 쪽 없는 읽기 순서입니다. 두 쪽 인쇄는 A4 세로에 본문 1·2쪽, 3·4쪽을 위아래로 짝지으며 표지·뒤표지는 별도 면에 놓습니다. 기존 제본용 기본값은 한 번 일반 인쇄로 옮기며 이후 부모가 명시적으로 선택한 제본 모드는 유지합니다. 소책자 인쇄와 브라우저 PDF 저장도 지원합니다. 제본용 소책자에는 4의 배수를 맞추기 위한 빈 쪽과 쪽 재배치가 필수이며, 선택 화면·미리보기에 이를 표시합니다. A4 가로, 짧은 쪽 뒤집기를 사용하며 프린터별 시험 인쇄가 필요합니다.

펼침 구성 책(R12)의 인쇄는 위 쪽 책 규칙과 별도입니다. ‘한 장에 펼침 하나’는 A4 가로 한 장에 펼침 하나를 놓고 펼침면 그림은 접는 선에서 이어지며 쪽 번호는 2k−1·2k입니다. ‘크게 읽기’는 A4 세로 한 장에 인쇄 쪽 하나이고 펼침면은 그림 반쪽씩 두 장이 됩니다. 책 전체가 한 글자 크기를 쓰며 단계별 하한(K2 14pt·K3 13pt·K4 12pt, 최소 11pt)을 지킵니다. K4와 E3·E4 영어가 있는 책은 ‘크게 읽기’를 먼저 고릅니다. 출력 범위는 펼침 번호로 적습니다. 측정은 `scripts/r12-print-fit.mjs`(`QA/r12-print-fit.json`)입니다.

검증: `node --test tests/*.test.mjs`. 공급자 계약 테스트는 모의 응답을 사용하며 실제 유료 API 화질·비용·CORS 성공을 보증하지 않습니다. 가족 계정의 두 기기 흐름(가입·복구 코드·받기·아이 읽기·로그아웃·복구·비밀번호 변경·삭제)은 `FAMILY_SIGNUP_CODE=<20자 이상> node scripts/r11-family-e2e.mjs 4800`(실제 클라우드 API, 메모리 D1·R2)를 띄운 뒤 같은 환경변수로 `node scripts/r11-family-scenarios.mjs http://127.0.0.1:4800/`를 실행해 확인합니다(Playwright 필요, 유료 요청은 막습니다).


## 장면 연결과 본문 인쇄

같은 장소에서는 확정 배경 시트와 앞쪽의 첫 장면·최근 장면을 함께 참조합니다. 배경의 출입구 형태·문 개수·창 위치·구조물 배치를 고정하고, 현재 본문과 이전 쪽의 사건도 전달합니다. 전체 장면은 한 쪽씩 순서대로 생성하며 필수 배경/첫 장면이 참조 한도에 걸리면 오류를 표시해 생략을 막습니다. 실제 생성 이미지의 완전한 기하학적 일치는 보장되지 않으므로 부모가 결과를 확인해야 합니다. 이미 확정된 책은 ‘복사본으로 그림·글 수정’으로 원본을 보존해 다시 생성할 수 있습니다.

기본 본문은 그림 아래에 별도 조판해 그림을 가리지 않습니다. 편집 미리보기와 기존 책의 인쇄에도 동일하게 적용하며, 과거 페이지의 상단·하단 겹침 설정은 기본 출력에 적용하지 않습니다. 인쇄 설정에서 그림 안 배치는 명시적으로 선택할 수 있습니다. 편집 화면의 본문 미리보기는 입력과 함께 바뀌며 확정 전에도 ‘글 포함 인쇄 미리보기’를 사용할 수 있습니다. 출력은 기존 ko/en 및 textKo/textEn 형식을 모두 읽습니다. 긴 글은 그림 영역과 글자 크기를 조절하며 여전히 넘치면 경고와 함께 화면의 인쇄 버튼을 비활성화합니다. 브라우저/프린터의 출력 배율은 실제 크기 100%로 확인해 주세요.

이야기 전문은 짧은 전체 글자 수 지시 대신 단계별 문장 수·어절 범위와 페이지 수를 기준으로 씁니다. 관찰·시도·결과·다음 결정 및 감각 묘사를 보강하되 선택한 K/E 단계는 유지합니다. 기존 책 본문은 자동으로 바꾸지 않습니다.


## 기기 이동과 로컬 데이터 보호

기존 브라우저 자료는 보존하며, 계정별 클라우드 연결을 제공합니다. 파일 이동은 보조 기능으로 유지합니다. 마법사와 줄거리 카드에는 단계별 글 모델의 한 줄 요약과 변경 링크를 제공합니다. 엔진·단계별 모델·요금·하이브리드는 부모 설정에서 관리하며, 저장 후 이야기로 돌아가면 해당 초안의 이후 요청부터 적용됩니다. 기존 전문과 그림은 보존합니다.

‘기기 이동 · 복구’에서 원래 기기의 그림·재료 포함 이동용 JSON을 내보내 모바일로 보낸 뒤 가져올 수 있습니다. 기존 ZIP도 압축을 직접 풀지 않고 선택할 수 있습니다. 파일에는 캐릭터·배경·시트·그림·음원·World·읽기 설정·초안을 담고 API 키·PIN은 제외합니다. 가져오기는 자료 수를 확인한 뒤 기존 라이브러리를 교체하며, 현재 기기의 PIN과 API 키는 유지합니다. 교체 전 localStorage 원문과 미디어 참조를 IndexedDB 복구용 보관함에 남깁니다. 미디어를 포함한 복구 파일은 내려받기를 누를 때 만듭니다. ‘복구용 보관본 내려받기’에서 파일을 받아 다시 가져올 수 있습니다. 이 파일 이동 동작 자체는 서버로 업로드하지 않습니다. 클라우드 연결 뒤에는 별도의 자동 저장이 적용됩니다.

저장 자료가 손상되거나 읽기 권한이 없으면 원본을 샘플 데이터로 덮어쓰지 않습니다. 읽기 실패를 안내하고 저장을 막으며 원본 보관·백업 가져오기를 제공합니다. 앱은 다른 기기의 브라우저 데이터를 원격으로 읽거나, 이미 지운 브라우저 자료를 서버에서 복원할 수 없습니다.


## 계정별 클라우드 동기화

로그인은 두 가지입니다.

- **가족 아이디**: 아이디·비밀번호로 이 사이트의 `/api/cloud/auth/*`(signup·login·logout·recover·password·delete)에 로그인하고, 받은 세션 토큰을 `X-Family-Session` 헤더로 보냅니다. 비밀번호는 브라우저에서 PBKDF2로 만든 확인값만 보내며, 서버는 토큰·복구 코드·비밀번호를 원문으로 저장하지 않습니다. 계정 만들기는 서버 비밀값 `FAMILY_SIGNUP_CODE`(가족 초대 코드)를 설정한 배포에서만 열립니다. 이 값은 추측할 수 없는 20자 이상의 무작위 값이어야 합니다(예: `openssl rand -base64 24`). 서버는 초대 코드를 가장 먼저 비교하고, 틀린 초대 코드는 따로 세므로 초대 코드를 아는 가족의 가입은 틀린 시도 때문에 막히지 않습니다. 가입 때 한 번만 보여 주는 복구 코드로 비밀번호를 잊었을 때 새 비밀번호를 만들며, 복구하면 다른 기기는 모두 로그아웃됩니다. 비밀번호를 바꿀 때 다른 기기 로그아웃을 고를 수 있고, 그 순간 이전 비밀번호로 진행 중이던 로그인도 세션을 받지 못합니다. 계정을 지우면 클라우드 책장·그림·음원이 지워지고 이 기기의 책은 남습니다. 가족 계정의 그림·음원 보관 공간은 5GB(파일 2만 개)입니다. 다 쓰면 그 사실을 알려 주고, 같은 책장은 자동으로 다시 올리지 않다가 책장이 바뀌거나 부모가 ‘이 기기 자료 클라우드에 저장’을 누를 때 다시 올립니다(서버는 선언된 크기로 먼저 거절해 본문을 받지 않습니다).
- **ChatGPT 계정**: Sites가 검증해 전달하는 `oai-authenticated-user-id` 헤더로 계정을 나눕니다. `X-Family-Session` 헤더가 있으면 그쪽이 우선하고, 만료되거나 잘못된 가족 토큰은 ChatGPT 계정으로 넘어가지 않고 ‘가족 아이디 로그인이 끝났어요’로 알립니다(요청 도중 끝난 경우도 같습니다).

기존 자료가 있는 PC에서 가족 아이디나 ChatGPT로 로그인한 뒤 ‘이 기기 자료 클라우드에 저장’을 한 번 선택합니다. 같은 계정으로 로그인한 새 휴대폰·태블릿이 기본 샘플만 가진 상태(PIN·설정만 있고 가족이 만든 책·재료는 없음)면 고르지 않고 클라우드 자료를 그대로 받습니다. 가족이 만든 자료가 있는 기기는 어느 쪽 자료를 쓸지 고릅니다. 이후 부모 모드의 변경은 1.5초 지연 저장하며 포커스 복귀/20초 간격으로 다른 기기의 새 버전을 확인합니다. 아이 모드에서 책을 읽기만 한 기록(읽은 횟수·마지막으로 읽은 때·날짜별 읽기·종이책 읽기)은 변경으로 세지 않아 저장 대기나 충돌을 만들지 않고, 다른 기기의 새 책을 받을 때 이 기기의 읽기 기록을 합쳐 둡니다. 두 기기에서 내용이 모두 바뀌면 ‘다른 기기에서 방금 저장했어요’로 알리고 어느 자료를 사용할지 선택할 때까지 보존합니다. 클라우드보다 책이 적은 기기에서 저장하려 하면 확인 창에 두 권수를 보여 주고 클라우드 책장이 이 기기 것으로 바뀐다고 경고합니다. 편집 중인 줄거리·책이 있을 때는 자동 불러오기를 미룹니다.

모든 미디어와 스냅샷은 그 계정만 읽습니다. 업로드에는 같은 출처 및 로그인 계정 확인 헤더를 요구하며, 비교 후 교체(CAS) 버전 검사로 다른 기기의 변경을 조용히 덮어쓰지 않습니다. PIN·API 키는 클라우드에 보내지 않습니다. 다른 계정으로 로그인할 때의 규칙은 이렇습니다. 잠기지 않은 채 이전 계정에 저장을 마친(클라우드에 저장됨) 기기나 클라우드와 연결한 적이 없는 기기는 이 기기 자료를 그대로 보여 주고 어느 쪽 자료를 쓸지 고르게 하며, 고르기 전에는 아무것도 올리지 않습니다. 그 밖의 기기(저장 대기·충돌 중이거나 이미 잠긴 기기)와 로그아웃한 기기는 이전 계정의 책장을 화면에서 잠그고, 현재 계정의 클라우드 자료를 불러오거나 이전 계정으로 다시 로그인하게 합니다. 잠긴 기기에서는 부모 PIN을 확인한 뒤 ‘이 기기 자료로 계속 쓰기’로 클라우드 연결만 끊고 이 기기의 책을 그대로 쓸 수 있습니다(나중에 다시 로그인하면 어느 쪽 자료를 쓸지 고릅니다). 잠금이 풀리면 책장 화면에서 다시 시작합니다. FULL AUTO가 도는 동안에는 계정을 바꾸지 않습니다. 현재 계정의 자료를 불러오기 전 기기의 원문과 미디어 참조는 복구함에 남깁니다.

기존 정적 UI 소스는 `dist/`에 유지합니다. 공식 Sites Vinext 런타임은 `cloud-runtime/`이며 `npm run build`가 UI를 public에 복사해 `cloud-runtime/dist/`의 Worker·자산·Sites 메타데이터를 빌드합니다. `.openai/hosting.json`의 논리 바인딩은 `DB`(D1), `BUCKET`(R2)입니다. `cloud-runtime/db/schema.ts` 변경 후 `npm run db:generate`로 SQL·Drizzle 메타데이터를 생성합니다. 배포 아카이브는 빌드한 client/server/.openai 산출물을 표준 `dist/` 위치에 포함해야 합니다.

설정은 우리 집·읽기·잠금 / 글 엔진·이야기 품질 / 그림 World·화풍의 세 탭에서 관리합니다. 이야기 만들기는 재료→주제와 분위기→읽기와 형식→만들기로 진행하며, 리더의 글자 크기는 기기에 저장됩니다. 유료 엔진의 유사 그림은 책당 확인 후 선택한 쪽만 추가 생성합니다.
