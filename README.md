# 271

네이버 스마트스토어에 새 상품이 올라오면 한 화면에서 모아보는 개인 도구입니다.

```
store-watch-core/   조회·파싱·정렬 (프레임워크 없음, 테스트 47건)
web/                화면 + 최소 서버 (네이버 스토어 디자인 참고)
```

## 띄우기

```bash
cd web
npm install
npm run demo     # http://localhost:5173 — 가상 데이터로 화면 확인
npm start        # 실제 네이버 조회
```

두 폴더는 각각 독립적으로 설치·검증합니다.

```bash
cd store-watch-core && npm install && npm test   # 47건
```

## 지금 상태

화면과 조회 로직은 다 붙어 있고, 마지막 하나가 걸려 있습니다.

**네이버가 클라우드 IP를 막습니다.** 두 개발 환경에서 연속으로 `/i/v1/stores/{storeId}`가 429를 반환했습니다(네이버가 직접 주는 한국어 오류 페이지). 조회가 실패하는 경로는 실제 트래픽으로 확인했지만, **성공하는 경로는 아직 실제 데이터로 검증하지 못했습니다.**

다음 확인은 개인 회선 PC에서 `npm start`로 띄워 보는 것입니다. 거기서도 막히면 서버를 경유하는 웹 방식이 아니라, 폰에서 직접 호출하는 네이티브 앱 쪽으로 방향을 틀어야 합니다.

자세한 내용은 각 폴더의 README를 보세요. 특히 `store-watch-core/README.md`의 "설계에서 지켜야 할 것" 네 가지는 화면을 고칠 때도 무너뜨리면 안 됩니다.
