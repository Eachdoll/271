# 동화공방

기획서의 MVP 흐름을 구현한 브라우저 앱입니다. `dist/`를 정적 서버에서 제공하면 됩니다.

## 포함 기능

- 부모 PIN과 읽기 전용 아이 모드
- 캐릭터 후보 선택·버전·배경 저장
- Google·OpenAI·BFL·fal·ComfyUI 이미지 플러그인, AES-GCM 키 저장, 동일 프롬프트 3개 엔진 비교
- World별 엔진·화풍, 시트 재생성 경고, 참조 시트와 스타일 이미지의 동시 전달·시드 기록
- 생성 이미지 IndexedDB 보관, 시트 미리보기 후 부모 확정
- 재료 선택 → 주제·언어·길이 → 줄거리 편집 → 쪽별 편집 → 부모 확정
- 책장 검색·필터·즐겨찾기·읽기 기록·시리즈 이어 만들기
- 한글·영어 브라우저 음성 합성과 이어 듣기·속도·듣기 전용 모드
- A4 단면·두 쪽·소책자 인쇄, 쪽 범위, 컬러·흑백, 브라우저 PDF 저장
- ZIP 백업과 JSON 복원, 브라우저 로컬 저장
- 처음 온라인으로 연 뒤 같은 브라우저에서 앱과 저장된 책을 오프라인으로 다시 열기

## 생성 범위

이야기 글은 로컬 주제 템플릿입니다. 이미지 생성은 부모 설정에서 엔진의 API 키를 저장하거나 ComfyUI 엔드포인트와 API 워크플로를 설정해 사용합니다. 키 없이도 고정 캐릭터 SVG로 샘플 흐름을 사용할 수 있습니다. 실제 생성은 부모가 명시적으로 누르는 시트/장면/비교 버튼에서만 실행되며 공급자 비용이 발생할 수 있습니다. [이미지 플러그인 구조와 공급자별 동작](IMAGE_GENERATION.md)을 참고하세요.

사진 특징 추출, 자동 비전 검수, 부모 음성 녹음, 클라우드 동기화, QR 음원 및 네이티브 iOS·Android 앱은 포함하지 않았습니다. 생성 이미지의 해상도는 공급자·요청 크기에 따르며 브라우저 인쇄 대화상자에서 PDF로 저장합니다.

PIN은 SHA-256 해시로 로컬 저장되며 부모 화면의 우발적 접근을 막는 장치입니다. 서버 인증을 대신하지 않습니다. 새로고침하면 부모 잠금이 다시 걸립니다. 가족 설정과 책의 글은 localStorage, 큰 생성 이미지는 IndexedDB에 저장되므로 기기 간 자동 동기화되지 않습니다.

인쇄 PDF는 브라우저 인쇄 대화상자에서 'PDF로 저장'으로 만듭니다. SVG 그림은 벡터입니다. 소책자는 A4 가로, 짧은 쪽 뒤집기 안내를 사용하며 프린터별 시험 인쇄가 필요합니다.
