# 동화공방

부모가 캐릭터와 장소를 만들고 한글·영어 그림책을 엮는 브라우저 앱입니다. `dist/`를 정적 서버로 제공합니다.

## 포함 기능

- 부모 PIN, 읽기 전용 아이 모드, 책장·즐겨찾기·시리즈·인쇄·음성 합성
- 등장인물·배경 설정 수정, 삭제와 복원, 이전 책의 외모·장소 스냅샷 보존
- 이야기 주제별 조연 설정 추천 → 선택한 World 엔진으로 시트 생성 → 부모 확인 → 재료 서랍·작성 중 이야기 추가
- 사진 1~3장으로 캐릭터 시트·World별 배경 시트 생성(사진의 구조·창·문·가구·소품과 고정 배치 보존), 완성 그림 무료 가져오기. 원본 사진은 메모리에만 보관하고 정리하며, 생성 결과만 IndexedDB에 저장
- Google·OpenAI·BFL·fal·ComfyUI 이미지 플러그인, 기기 내 무료 그림 템플릿, AES-GCM API 키 보관, 같은 프롬프트 3개 엔진 비교
- 사용자 화풍 추가·수정·삭제·금칙어, 고정 세 장면 시험 후 스타일 시트 1~2장 고정
- 캐릭터 옷장 정면·전신 2장 승인, 책별·쪽 범위별 모습 선택, 추천 사전·부모 요청 Google API로 한글 설명을 영어로 번역
- 여러 World 배리에이션 저장·선택, World별 독립 글·그림 엔진·화풍·연결 설정·세계관 메모, 새 World의 시트 재생성 안내
- 배경 시트 사전 생성(draft → final → 부모 승인), 장소의 문·창·가구·소품 고정, World별 승인 시트와 기존 책 스냅샷 보존
- World별 엔진·화풍, 실제 커버 PNG를 기준으로 한 수채화 프리셋, 캐릭터 시트와 스타일 참조의 동시 전달, 시드 기록
- 한글 K1~K4와 영어 E0~E4 별도 설정, JSON levelSpec, 영어 독립 문형 작성, 검사 후 최대 2회 자동 재작성
- SR 렉사일 입력에 따른 영어 단계 추천, 본문 기반 AR·렉사일 추정, 같은 난이도 피드백 두 번 뒤 단계 변경 제안 · 부모가 적용할 때만 변경
- ZIP 백업과 JSON 복원, 오프라인 앱 셸과 책 재열기

## 생성과 검사 범위

이야기는 별도 글 엔진으로 줄거리 비트 → 한글·영어 전문 → 쪽 나누기의 세 단계 LLM 호출을 사용합니다. 부모가 단계별 승인·수정·부분 재생성을 하며 단계 결과는 초안에 저장합니다. 로컬 모델과 API 최종 전문을 합친 하이브리드도 지원합니다. 부모 설정에서 GPT-6.1 Sol·GPT-6 Astra, Gemini 4 Argon, Claude Sonnet 5.5·Opus 5.5·Fable 5.1 등 상위 글 모델을 선택하고 모델별 요금으로 추정합니다. 이전 초안의 모델은 명시적으로 설정을 적용할 때만 바뀝니다. 7비트와 12쪽을 구분하고 쪽 수가 맞지 않는 저장 초안은 기존 글을 보존해 복구할 수 있습니다. API 실패를 템플릿으로 대체하지 않으며 고정 데모는 명시적 버튼과 라벨로 구분합니다. 조연 설정 추천은 기기 내 주제별 후보입니다. 자세한 규칙은 [글 생성 문서](TEXT_GENERATION.md)를 참고하세요.

다음 편은 이전 책의 원문·최종 장면·인물 관계·장소·결말을 읽고 새 사건을 만듭니다. 그림은 이전 편의 확정 캐릭터·스타일·집/방/장소 참조를 유지하며 해당 쪽의 장소만 참조합니다. 이전 책과 재료는 보존합니다.

그림은 부모가 생성 버튼을 누를 때 선택한 공급자 API 또는 ComfyUI로 생성합니다. 무료 샘플 엔진은 고정 SVG/Canvas 템플릿이며 사진 변환, 커버의 정교한 수채화, 이미지 레퍼런스 해석을 수행하지 않습니다. Google Gemini 웹 앱의 무료 한도는 이 앱의 API 호출에 사용할 수 없습니다. 웹 앱에서 직접 만든 그림을 내려받아 무료로 가져올 수 있습니다. [공식 Google API 요금표](https://ai.google.dev/gemini-api/docs/pricing)와 [이미지 플러그인 문서](IMAGE_GENERATION.md)를 참고하세요.

읽기 검사는 Python 없이 브라우저에서 FK, Revised Spache와 Dale–Chall 공식을 직접 계산합니다. 음절 수와 한글 연결어미는 휴리스틱이며 공식 AR·Lexile·KReaD 점수가 아닙니다. 공개 Dolch·Fry 및 각 지수의 독립 친숙 어휘 데이터를 포함합니다. 한글 등급 자료가 없으면 어휘 검사만 생략하며 부모가 CSV를 넣을 수 있습니다. 기본값은 K1/E0, SR과 난이도 피드백은 추천 후 부모 확인 방식입니다.

캐릭터·옷장·사진 후보는 draft로 먼저 확인하고, 최종 생성 버튼에서 final 품질로 다시 만들고 승인합니다. 스타일 시험과 엔진 2~3개 비교는 draft입니다. 책 확정에서 최종 본문과 표지를 만들기 전 예상 비용을 확인합니다. 실제 API가 금액을 반환한 경우에만 실제 비용을 기록하며 나머지는 추정입니다. 모델과 참고 단가는 `image-generation/models.js`에 모았습니다.

[로컬 Node 이미지 프록시](image-proxy/README.md)를 선택적으로 연결할 수 있습니다. 프록시에서는 환경변수 키만 사용하고 브라우저의 저장된 키를 보내지 않습니다. 정적 Site 자체는 Node 프록시를 실행하지 않습니다.

부모 녹음은 언어별로 TTS보다 먼저 재생합니다. OpenAI 키가 있으면 승인 후 쪽별 음원과 타임스탬프를 저장할 수 있으며, 키가 없을 때의 기기 음성은 사전 저장할 수 없습니다. 녹음·정렬 실패의 하이라이트는 근사 위치로 표시합니다. 음원도 백업/복원에 포함합니다. 이어 듣기 기본 OFF, 손 넘김과 스와이프는 재생을 시작하지 않습니다.

## 저장과 실행

책 글·설정은 localStorage, 큰 그림·음원은 IndexedDB에 보관합니다. API 키 평문과 원본 사진은 라이브러리 백업에 포함되지 않습니다. PIN 화면 잠금 해시와 별도로 API 키는 PIN에서 PBKDF2로 파생한 AES-GCM 키로 암호화합니다. 파생 암호화 키는 메모리에만 두고 PIN 변경 때 저장된 API 키를 다시 암호화합니다. 기기 내 PIN은 서버 인증을 대신하지 않습니다. 새로고침하면 부모 잠금이 다시 걸리고 기기 간 자동 동기화는 없습니다.

기본 인쇄는 A4 가로 한 면 한 쪽, 빈 쪽 없는 읽기 순서입니다. 두 쪽 인쇄는 A4 세로에 본문 1·2쪽, 3·4쪽을 위아래로 짝지으며 표지·뒤표지는 별도 면에 놓습니다. 기존 제본용 기본값은 한 번 일반 인쇄로 옮기며 이후 부모가 명시적으로 선택한 제본 모드는 유지합니다. 소책자 인쇄와 브라우저 PDF 저장도 지원합니다. 제본용 소책자에는 4의 배수를 맞추기 위한 빈 쪽과 쪽 재배치가 필수이며, 선택 화면·미리보기에 이를 표시합니다. A4 가로, 짧은 쪽 뒤집기를 사용하며 프린터별 시험 인쇄가 필요합니다.

검증: `node --test tests/*.test.mjs`. 공급자 계약 테스트는 모의 응답을 사용하며 실제 유료 API 화질·비용·CORS 성공을 보증하지 않습니다.


## 장면 연결과 본문 인쇄

같은 장소에서는 확정 배경 시트와 앞쪽의 첫 장면·최근 장면을 함께 참조합니다. 배경의 출입구 형태·문 개수·창 위치·구조물 배치를 고정하고, 현재 본문과 이전 쪽의 사건도 전달합니다. 전체 장면은 한 쪽씩 순서대로 생성하며 필수 배경/첫 장면이 참조 한도에 걸리면 오류를 표시해 생략을 막습니다. 실제 생성 이미지의 완전한 기하학적 일치는 보장되지 않으므로 부모가 결과를 확인해야 합니다. 이미 확정된 책은 ‘복사본으로 그림·글 수정’으로 원본을 보존해 다시 생성할 수 있습니다.

기본 본문은 그림 아래에 별도 조판해 그림을 가리지 않습니다. 편집 미리보기와 기존 책의 인쇄에도 동일하게 적용하며, 과거 페이지의 상단·하단 겹침 설정은 기본 출력에 적용하지 않습니다. 인쇄 설정에서 그림 안 배치는 명시적으로 선택할 수 있습니다. 편집 화면의 본문 미리보기는 입력과 함께 바뀌며 확정 전에도 ‘글 포함 인쇄 미리보기’를 사용할 수 있습니다. 출력은 기존 ko/en 및 textKo/textEn 형식을 모두 읽습니다. 긴 글은 그림 영역과 글자 크기를 조절하며 여전히 넘치면 경고와 함께 화면의 인쇄 버튼을 비활성화합니다. 브라우저/프린터의 출력 배율은 실제 크기 100%로 확인해 주세요.

이야기 전문은 짧은 전체 글자 수 지시 대신 단계별 문장 수·어절 범위와 페이지 수를 기준으로 씁니다. 관찰·시도·결과·다음 결정 및 감각 묘사를 보강하되 선택한 K/E 단계는 유지합니다. 기존 책 본문은 자동으로 바꾸지 않습니다.
